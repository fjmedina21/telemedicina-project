# Flutter — aplicación móvil

Esta carpeta será la **raíz del proyecto Flutter** compartido por ambos colaboradores (`pubspec.yaml` en `app/src/` y código Dart convencional en `app/src/lib/`). Crear el proyecto aquí una vez se definan nombre de paquete y plataformas.

Antes de comenzar, consultar la [guía de colaboración](../../.ai/docs/TEAM_WORKFLOW.md) y las specs correspondientes.
