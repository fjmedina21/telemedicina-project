# Portal web de telemedicina

Este directorio está reservado para el **portal médico y administrativo**: agenda profesional, admisión, gestión de encuentros clínicos, validaciones y operaciones de soporte, según las specs M01–M12.

La tecnología frontend todavía no está seleccionada. Se decidirá antes de generar el proyecto (por ejemplo, React, Angular u otra alternativa). El portal consumirá los mismos contratos versionados de la API en `api/src/` y deberá respetar los roles clínicos y administrativos definidos.

En `.ai/collaboration.json`, el área `portal` está habilitada provisionalmente para ambos colaboradores hasta que acuerden quién será su responsable principal.
