# ASP.NET Core — API de telemedicina

Esta carpeta está reservada para la solución ASP.NET Core (proyectos `.csproj` dentro de `api/src/`) bajo responsabilidad principal de `backend_mobile`. OpenAPI será el contrato compartido con Flutter.

Antes de comenzar, elegir la versión objetivo de .NET, el esquema de persistencia y el flujo de migraciones.
